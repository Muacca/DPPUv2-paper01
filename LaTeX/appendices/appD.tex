\section{Displaying potentials and phase diagrams}\label{appD}
\subsection{Coordinates, parameters, and plotted quantities}
Potential curves and phase diagrams specify the geometry, action variant,
variation path, and fixed $\kappa,L$ and torsion coefficients.
Conversion from code parameters $V_\tau,\eta_\tau$ to the main-text
$V,\eta$ reverses both signs according to Appendix~\ref{appA}.
Ordering an axis increasingly also requires reordering the associated data.

Use $a=r/2$ for the actual sphere radius and $\ell_i=2\pi R_i$
for torus circumferences. Convert the axial coefficients as well:
$\chi=\eta/2$ and $\zeta=2\pi\eta$, respectively.

\subsection{Extrema and phase labels}
For Type~I, $\Delta U$ is the action difference between a positive-radius
maximum and minimum; Type~II depth uses the origin limit as its reference.
The displayed quantity must identify this distinction.
A radius minimum does not establish a vacuum of the full field equations
or dynamical stability.

Type~III includes monotone functions, flat functions, runaway behavior,
and stationary inflections.
An unresolved discriminant band or a failed calculation is recorded
separately from an analytic classification.
A missing minimum radius in a CSV is not displayed as a minimum at zero.

\subsection{Matching curves to numerical outputs}
Relating a phase label or extremum to a curve requires the same potential,
input parameters, and variation path.
A positive overall volume factor preserves extremum positions and types,
and scales action values and heights.
Comparisons of vertical scales across geometries use the volumes and
length conventions of Section~\ref{sec3}.
Appendix~\ref{appC} defines numerical columns; Appendix~\ref{appF}
gives calculation procedures.

\subsection{Data accompanying the figures}
The repository directory \texttt{data/paper\_v3} provides input domains, data columns, and the PNG/SVG index for Figures 1--9 and Tables 1--7. These data use geometric $V,\eta$ and a distinct schema from the scanner CSV in Appendix~\ref{appC}.
