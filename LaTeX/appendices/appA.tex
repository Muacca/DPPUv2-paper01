\section{Connection components and the code-input dictionary}\label{appA}
\subsection{Levi--Civita connection}
Indices and structure coefficients follow Section~\ref{sec2}.
The nonzero components on $S^3$ are
\begin{equation}
\Gamma^{\mathrm{LC}}_{012}=-\Gamma^{\mathrm{LC}}_{021}
=\Gamma^{\mathrm{LC}}_{120}=-\Gamma^{\mathrm{LC}}_{102}
=\Gamma^{\mathrm{LC}}_{201}=-\Gamma^{\mathrm{LC}}_{210}
=\frac2r.
\tag{A-01}\label{eq:A-01}
\end{equation}
All components vanish on $T^3$. For Nil, the nonzero components are
\begin{equation}
\Gamma^{\mathrm{LC}}_{012}=\Gamma^{\mathrm{LC}}_{021}=\frac1{2R},
\quad
\Gamma^{\mathrm{LC}}_{102}=\Gamma^{\mathrm{LC}}_{120}=-\frac1{2R},
\quad
\Gamma^{\mathrm{LC}}_{201}=-\Gamma^{\mathrm{LC}}_{210}=-\frac1{2R}.
\tag{A-02}\label{eq:A-02}
\end{equation}
They satisfy
$C+\Gamma^{\mathrm{LC}}_{\cdot cb}-\Gamma^{\mathrm{LC}}_{\cdot bc}=0$.
The spatial scale is constant with respect to frame position.

\subsection{Contortion from geometric torsion}
Substituting the axial and vector parts in \eqref{eq:M2-03} gives
\begin{equation}
K^{\mathrm{ax}}_{ijk}[T]=-\frac{\eta}{s}\varepsilon_{ijk},
\qquad
K^{\mathrm{vec}}_{abc}[T]
=-\frac13(\delta_{ac}V_b-\delta_{bc}V_a).
\tag{A-03}\label{eq:A-03}
\end{equation}
Cyclic permutations of the axial component are even, so the three-term
combination in the contortion formula reduces to $T_{ijk}$.
For the vector component, the $\delta_{ab}V_c$ terms cancel.
Both contortion components are antisymmetric in their first two indices.

\subsection{The input array}
Denote the torsion input array of the accompanying code by $\tau_{abc}$.
The code constructs the connection using
\begin{equation}
K^{\mathrm{code}}_{abc}[\tau]
=\frac12(\tau_{abc}+\tau_{bca}-\tau_{cab}),\qquad
\Gamma^{\mathrm{code}}=\Gamma^{\mathrm{LC}}+K^{\mathrm{code}}.
\tag{A-04}\label{eq:A-04}
\end{equation}
The geometric torsion reconstructed from this connection by the Cartan
equation is $T=-\tau$. The same-connection correspondence is therefore
\begin{equation}
\tau=-T,\qquad
\eta_\tau=-\eta,\qquad V_\tau=-V,\qquad
K^{\mathrm{code}}[-T]=K[T].
\tag{A-05}\label{eq:A-05}
\end{equation}
Simultaneously converting the corresponding parameters gives the same
connection, curvature, and action in both descriptions.
This does not mean reversing $K$ alone, or reversing $\eta$ while leaving
$V$ fixed.

In code-input variables, axial contortion is
$+\eta_\tau\varepsilon_{ijk}/s$, and vector contortion is
$+(\delta_{ac}(V_\tau)_b-\delta_{bc}(V_\tau)_a)/3$.
Both axial and vector geometric-torsion components have the opposite
sign, while $\eta^2,V^2,V\eta$ are unchanged.

\subsection{Scales and input domains}
An input interval $\eta_\tau\in[p,q]$ maps to $\eta\in[-q,-p]$,
and $V_\tau\in[v_-,v_+]$ maps to $V\in[-v_+,-v_-]$.
When plotting axes in ascending order, the associated data order
must also be reversed.

For the actual sphere radius,
\begin{equation}
a=\frac r2,\qquad
\frac{2\eta}{r}=\frac{2\chi}{a},\qquad
\chi=\frac{\eta}{2}=-\frac{\eta_\tau}{2}.
\tag{A-06}\label{eq:A-06}
\end{equation}
For torus circumferences,
\begin{equation}
\ell_i=2\pi R_i,\qquad
\frac{2\eta}{R_1}=\frac{2\zeta}{\ell_1},\qquad
\zeta=2\pi\eta=-2\pi\eta_\tau.
\tag{A-07}\label{eq:A-07}
\end{equation}
For Nil, the adopted lattice is fixed and $R$ is the common scale.
In all three geometries, $L$ is the actual circle circumference and
the coordinate $u$ has period one.

\subsection{Independent ingredients in action comparisons}
The simultaneous sign conversion is a change of description of the
same connection. The two-form coefficients in NY, the integration volume,
and the action variant are separate definitions; they are not absorbed
by the sign dictionary. Both descriptions use the same
$n_{\mathrm{REE}}=\varepsilon R/2$ and the adopted volumes.
