\section{Numerical classification and input domains}\label{appC}
\subsection{Input meaning and ranges}
In the accompanying parameter-scan script, arguments \texttt{V} and
\texttt{eta} are the coefficients $V_\tau,\eta_\tau$ of the array
defined in Appendix~\ref{appA}.
Convert to main-text geometric torsion by $V=-V_\tau$, $\eta=-\eta_\tau$;
$\theta$, the scales, $\kappa$, and $L$ are unchanged.

The CLI defaults are $V_\tau\in[0,5]$, $\eta_\tau\in[-10,5]$,
and $\theta\in[0,5]$, corresponding to $V\in[-5,0]$,
$\eta\in[-5,10]$. Endpoints are included; $V=0$ is not automatically
excluded. The respective point counts are 51, 151, and 51, giving
392,751 inputs per geometry and variant, or 3,534,759 inputs for all
three geometries and all three variants.
These numbers describe the size of an input grid.

The Python function \texttt{run\_scan} has different defaults:
6, 11, and 6 points, with $\eta_\tau\in[-5,5]$.
A record of default settings must identify the entry point.
The interactive viewer's default domains are
$V_\tau\in[0,10]$, $\eta_\tau\in[-15,5]$, $\theta\in[0,10]$,
corresponding to $V\in[-10,0]$, $\eta\in[-5,15]$.
These are subsets of the analytic parameter domain, not restrictions
on the formulas themselves.

The CLI interval becomes $\chi\in[-5/2,5]$ when using the actual sphere
radius, and $\zeta\in[-10\pi,20\pi]$ when using torus circumferences.
For example, the input pairs $(V_\tau,\eta_\tau)$
$(4,-3)$, $(4,-2)$, $(4,0)$, and $(4,3)$ correspond respectively
to main-text pairs $(-4,3)$, $(-4,2)$, $(-4,0)$, and $(-4,-3)$.

\subsection{The cubic classifier}
For registered potentials and callables supporting coefficient retrieval,
\texttt{get\_cubic\_coefficients} returns the coefficients of
$U=ar^3+br^2+cr$, and \texttt{analyze\_cubic\_stability} classifies them.
Here $(a,b,c)=P(A,B,C)$ includes the positive prefactor.
Signs, discriminants, and roots are treated as in Section~\ref{sec4}.

Coefficient and root arithmetic uses Decimal with 50-digit precision.
This does not give 50-digit accuracy to floating-point coefficients
supplied as input.
To control cancellation, for $b\ge0,c<0$ the positive root is evaluated
as $-c/(b+\sqrt{b^2-3ac})$.

The unresolved discriminant band is set by
$64\epsilon_{\mathrm{float}}\max(b^2,|3ac|)$.
A Type~III return in this band means that no strict minimum was resolved;
it does not prove that a small positive discriminant is exactly zero.
Boundary decisions should include the analytic inequalities.

If coefficients cannot be obtained for a general callable, a separate
bounded numerical search is used as a fallback.
Its conclusions are limited by the search window and resolution,
and do not have the same guarantees as the registered cubic criterion.
Exceptions from nonfinite coefficients or invalid inputs are not
counted as determinations of a new physical phase.

\subsection{Output format and preservation}
The CSV has eight columns:
\begin{lstlisting}[language={}]
topology, ny_variant, V, eta, theta, r0, delta_V, stability_type
\end{lstlisting}
The columns \texttt{V}, \texttt{eta} retain $V_\tau,\eta_\tau$.
For $S^3$, \texttt{r0} is the code scale $r$, not the actual radius $a$.
For Type~I, \texttt{delta\_V} is the difference from the positive-radius
maximum to the minimum; for Type~II, it is the depth from the origin
limit. For Type~III without a minimum, \texttt{r0} and \texttt{delta\_V}
are blank. These two kinds of height must not be plotted as the same
kind of barrier.

The aggregate filename is
\path{dppu_scan_all_{timestamp}.csv}, and individual filenames are
\path{dppu_scan_{topology}_{ny_variant}_{timestamp}.csv}.
Since the CSV does not contain all code-version and volume-convention
information, preserve the command, version, conventions, and log separately.

\subsection{Interpreting aggregate results}
Phase fractions and failure rates require an input population for which
the calculation actually completed.
Record unresolved numerical boundaries, input errors, failed numerical
searches, and exactly monotone functions as distinct cases.
A scan classifies the selected grid; conditions over the whole parameter
domain follow from the analytic results of Section~\ref{sec4}.
